# 002 API

## Purpose
Define the external API contracts consumed by this plugin (Mapflow backend REST API).

## Content

Interface type: REST JSON over HTTPS (plugin is the client, Mapflow backend is the server).

Base URL: `https://whitemaps-{env}.mapflow.ai/rest` where `{env}` is one of: production (empty), staging, internal, duty.

### Authentication

Two mechanisms:
1. **Basic Auth (Token):** Header `Authorization: Basic {token}`: the Mapflow API token is itself
   `base64(login:password)`. The plugin decodes it and stores login and password as a Basic
   configuration in the QGIS authentication database, never in `QgsSettings` (see `003_local_storage.md`).
2. **OAuth2 (Keycloak):** Authorization Code with PKCE. The realm is
   `https://auth.mapflow.ai/auth/realms/mapflow` in production and
   `https://auth-{env}.mapflow.ai/auth/realms/mapflow-{env}` in every other environment (staging, internal,
   duty). The plugin runs the flow itself (browser sign-in, a local redirect listener) and renews the
   tokens with its own timer; only the refresh token is kept, in the QGIS authentication database.

Credentials are attached only to requests whose scheme, host and port are the API's. A request for
another origin, or over plain `http://` (a local test host aside), goes out without them: URLs that
arrive in API responses (`tileJsonUrl`, `previewUrl`) are fetched through the same client.

Custom header on all requests: `x-plugin-version: {version}`.

### Error model

Multiple formats depending on source:
- Standard API: `{"code": string, "message": string, "params": object}`
- Data Catalog: `{"detail": {error_data}}`
- Fallback: raw response text

### Versioning policy
The plugin declares `x-plugin-version` on every request. The backend may respond with update notifications. Breaking API changes are reflected in major plugin version bumps.

`GET /version` answers the plugin version the backend expects, as text. The plugin asks at sign-in: a
higher **major** version than its own blocks the plugin with a message that says to upgrade. A higher
minor or patch version is not announced; "Check for updates…" in the plugin menu asks the QGIS plugin
repositories on demand.
